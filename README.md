# Basic Git Commands

### 1. Daily Workflow
* Check status: `git status`
* Add file to staging: `git add <file>` or `git add .`
* Commit changes: `git commit -m "your message"`
* Push to GitHub: `git push origin main`

### 2. View History
* View compact log: `git log --oneline`

### 3. Branching
* Create and switch branch: `git checkout -b <branch_name>`
* Switch branch: `git checkout <branch_name>`
* Check current branch: `git branch`

### 4. Stash (Save temporary work)
* Save work: `git stash save "message"`
* Restore work: `git stash pop`
